Privacidade e seus dados

Última atualização: 13 de novembro de 2026

O que o app guarda

O app guarda o endereço de e-mail da conta e os dados que você cria, como tarefas, etapas, horários, modelos e preferências da rotina. A senha é gerenciada pelo Firebase Authentication e não é salva no código do site.

Onde os dados ficam

Os dados sincronizados ficam no Cloud Firestore do projeto Minha Rotina, hospedado pelo Firebase. As regras separam os registros pelo identificador da conta autenticada, e o app pede confirmação do e-mail antes de carregar os dados. Uma cópia também pode permanecer no armazenamento local do navegador, e você pode baixar um arquivo de backup em Ajustes.

A administradora do projeto Firebase tem acesso administrativo ao banco e pode acessar os dados nele armazenados. A confirmação do e-mail e as regras por conta não impedem esse acesso administrativo.

O código do site é público no GitHub e é servido pelo GitHub Pages. A configuração Firebase do app Web também é pública; o acesso aos dados é controlado pelas regras do banco.

Como usar, exportar e excluir

Use o app apenas para sua organização pessoal. Durante o beta, não insira informações altamente confidenciais. Em Ajustes, você pode baixar ou restaurar uma cópia e excluir a conta e os dados sincronizados. Depois da exclusão, cópias locais em outros aparelhos podem precisar ser removidas nos dados do navegador desses aparelhos.

Serviços e custos

O beta usa Firebase Authentication, Cloud Firestore e GitHub Pages nos planos gratuitos configurados. Não adicionamos analytics nem serviços pagos. Os fornecedores podem processar dados técnicos necessários para operar seus serviços, sujeitos às políticas deles. As cotas gratuitas podem limitar temporariamente o acesso se forem excedidas.

Feedback

O link de feedback abre uma solicitação pública no GitHub. Não envie senhas, e-mails, horários pessoais ou outros dados privados nessa solicitação.
